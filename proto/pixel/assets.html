Mega-office asset options

What each candidate looks like, and whether we may ship it in a public repo and hosted demo. "Redistributable" is the bar: most itch.io packs allow use in games but forbid redistributing the files.

Three routes

A · Open LPC building kitships everywhere
  • Real walls, floors, doorways, kitchens, restrooms; characters with a sit pose
  • Consistent 32px style; leans cosy/rustic, less corporate
  • Attribution file required (many authors)
B · Premium modern office, bring-your-own~$2–$15, not in repo
  • LimeZu Modern Office or Donarg: most corporate, most realistic
  • Like Pixel Agents: the repo ships the CC0 default; the app loads a pack you bought from a local folder
  • The hosted demo could only use it if the licence allows a built project (check first)
C · Keep 2dPig, add drawn architectureno new assets
  • Draw thick walls, doorways, corridors, meeting rooms and kitchens in code, in the 2dPig style
  • Cheapest and consistent with the tower; realism limited by the small prop set

Recommended: the LPC building kit (all open licences, one consistent 32px style)

[LPC] Walls + [LPC] FloorsCC-BY-SA 3.0 / 4.0
  • 300+ walls with auto-tiling corners, 32 ceiling trims, 100+ floors (carpet, wood, tile)
  • This is what makes rooms, corridors and doorways read as a real building

Other usable packs

[LPC Revised] The OfficeCC-BY-SA 3.0 / OGA-BY 3.0
  • Real building interior: walls, floors, doors, desks, laptops, sinks, meeting tables
  • 32px LPC style, the open-source art standard; huge LPC ecosystem (kitchens, bathrooms, furniture)
  • Pairs with LPC characters (walk, sit) or MetroCity at 2×
  • Attribution required; OGA-BY avoids share-alike
